# TraceHen frontend — house rules

- **Expo (managed workflow), SDK 58.** The app runs in Expo Go (`npx expo start`, scan the QR on the phone). No `android/` or `ios/` directory in the repo — native projects are generated by `npx expo prebuild` when a production build is needed. The Android package is `pk.edu.uaf.tracehen` (app.json).
- **React Navigation, typed.** Every route name lives in
  `src/navigation/types.ts` (`RootStackParamList`). Never navigate by a path
  string; never add a route without adding it to `RootStackParamList` AND to
  `src/navigation/RootNavigator.tsx` AND making it reachable from a screen,
  a BottomNav tab or the login flow.
- **Routes live in `src/screens/` (never `src/app/`).** One file per route.
- **Camera (Scan screen) uses expo-camera.** The camera permission is
  configured in app.json (expo-camera plugin) and requested at runtime
  directly (the system prompt only — no custom permission sheet).
  QR scanning uses `CameraView` `onBarcodeScanned` (barcodeTypes `['qr']`).
- **Fonts load via expo-font** (`useFonts` in App.tsx, Manrope in
  `assets/fonts/`). Never hard-code a font family in a screen — use
  `src/theme/typography.ts`.
- **Secure storage is expo-secure-store** (`src/services/storage.ts` only).
  Documents open in the system viewer via expo-sharing + expo-asset
  (no inline PDF renderer works in Expo Go). File picks use
  expo-image-picker / expo-document-picker.
- **No `any`, no dead code, no dead buttons.** Run `npm run lint`,
  `npm run tsc` and `npx expo export` before declaring anything done;
  all must pass with zero errors.
- **English only** in code, comments and UI.
- **Mock boundary:** demo data lives in `src/data/demoData.ts`; the single
  data layer is the store in `src/services/store.tsx` (AppStore / useApp).
  Screens never touch SecureStore/AsyncStorage directly — only
  `src/services/storage.ts` does. (`src/services/mockApi.ts` was deleted:
  dead code, superseded by the store.)
- **Chain rules (do not reintroduce):** chicken meat only — no eggs, no
  hatchery, no breeder, no halal attestation. Chain starts at the farm with
  chicks. Blockchain = entries only, never a gate or a block.
